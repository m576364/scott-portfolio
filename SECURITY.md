# Security Policy

## Supported surface

This repository publishes a **static** personal portfolio (HTML/CSS/JS) via GitHub Pages.

There is no authentication, database, or server-side application code in the hosted site.

## Reporting a vulnerability

Email **scott.streamer@gmail.com** with:

- Affected URL or file
- Description of the issue
- Steps to reproduce
- Impact assessment if known

Please do not run destructive or high-volume testing against GitHub infrastructure.

## Scope

In scope:

- XSS or script injection in this site's pages
- Sensitive data accidentally committed to the repo
- Broken access assumptions documented on the Security page that prove incorrect

Out of scope:

- Issues solely in third-party sites linked from this portfolio (Credly, Coursera, LinkedIn, GitHub)
- Social engineering against personal accounts
- Denial-of-service against GitHub Pages

## Response

I will acknowledge reports as soon as practical and remediate confirmed issues in this repository.
